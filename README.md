# CodeAlpha - Disease Prediction

## Objective
Demonstrate classification on a medical dataset using supervised machine learning.

## Dataset
Uses scikit-learn's built-in Wisconsin Breast Cancer dataset; no external download is required.

## Model and evaluation
- Random Forest classifier
- Stratified train/test split
- Accuracy, precision, recall, F1-score, and confusion matrix
- Example prediction on a held-out test record

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Disclaimer
For educational demonstration only. This model must not be used for diagnosis, screening, or treatment decisions.
